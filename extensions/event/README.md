# Event - Create Event effortless by AI

You can use this extension to create any event by context.

## Features

**Context Input**:

- [ ] User Input
- [ ] Selected text
- [ ] Selected Screenshot Area
- [ ] Current Email

**Event Type**:

- [ ] Apple Calendar Event
- [ ] Google Calendar Event
- [ ] Apple Reminder
- [ ] Google Task
- [ ] Microsoft To-Do
- [ ] TickTick?

**Supported AI Models**:

- [x] OpenAI
- [ ] Google Gemini
- [ ] Deepseek
- [ ] Local Model / Custom Model
